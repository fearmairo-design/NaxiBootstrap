# Naxi Bootstrap — Privacy Policy

**Effective date:** August 25, 2026

This Privacy Policy explains what information **Naxi Bootstrap** ("Naxi", "the Application", "we", "us") processes when you use the Windows application.

Naxi is a private, proprietary Windows utility. This policy is written based on the current application code and may be updated if the application's data handling changes.

## 1. Information We Collect

### 1.1 No account or profile data

Naxi does not currently require an account, registration, username, email address, password, or personal profile.

### 1.2 No built-in telemetry

The current application code does not intentionally implement analytics, advertising identifiers, behavioral tracking, crash-reporting services, or a remote telemetry system.

Naxi does not intentionally collect or sell personal information.

### 1.3 Local files

Naxi may read or write files that are necessary for its operation, including:

- the local `updatelog.json` file shipped with the application;
- temporary update files used while downloading and installing an application update;
- files in the application's installation directory needed to complete an update.

Naxi does not intentionally upload these local files as part of its normal operation.

## 2. Network Connections

Naxi can make network requests for the following purposes:

### GitHub

Naxi checks the project's GitHub repository for:

- the latest release version;
- the remote update log;
- the downloadable update package.

The current application is configured to use the repository:

`fearmairo-design/NaxiBootstrap`

These requests are made to GitHub's public API/raw-content infrastructure. GitHub may independently process technical information such as IP address, request metadata, and server logs according to GitHub's own policies.

### Discord

The "Join Discord" button opens a Discord invitation URL in the user's default browser.

Naxi does not receive or control information that you provide directly to Discord. Discord's own terms and privacy policy apply to your use of Discord.

### Roblox

The "Launch" function invokes the `roblox-player:` protocol to start the Roblox client installed on the user's computer.

Naxi does not replace the Roblox executable and does not control Roblox's data collection. Roblox's own terms and privacy policy apply to Roblox services.

## 3. Automatic Updates

When update checking is enabled and the application starts, Naxi may contact GitHub to determine whether a newer release is available.

If an update is available, Naxi can download the corresponding `.zip` release asset and temporarily extract it before replacing the application's files.

The application does not currently send a user account, email address, personal identifier, or application usage history to the update server.

## 4. Third-Party Services

Naxi relies on third-party infrastructure for certain functions:

- **GitHub** — release hosting, update metadata, and update downloads.
- **Discord** — community/invitation link opened by the application.
- **Roblox** — game/client launching through the installed Roblox client.

Those services operate independently from Naxi. Their own privacy policies, terms, cookies, logs, and data practices may apply when you interact with them.

## 5. Cookies and Tracking

Naxi itself does not use browser cookies, advertising cookies, web beacons, or similar tracking technologies.

A browser opened by Naxi may use cookies or other technologies belonging to the website being visited. Those technologies are controlled by the relevant third party.

## 6. Data Security

Naxi is designed to minimize the amount of information it processes.

However, no software, network connection, or computer system can be guaranteed to be completely secure. You are responsible for maintaining appropriate security on your device, including using trusted software sources and keeping Windows and security software up to date.

## 7. Children's Privacy

Naxi does not knowingly request personal information from children.

Because Naxi can launch Roblox and link to external services, those services may have their own age requirements and privacy rules. Users should review the applicable third-party policies.

## 8. Data Retention

Naxi does not maintain a central user database.

Local temporary update files are created only as needed for the update process and are intended to be removed after the update. Local files that remain on the user's computer are controlled by the user and the operating system.

Third-party services may retain technical request information under their own policies.

## 9. Your Choices

You can:

- choose not to use the update functionality;
- choose not to open Discord or other external links;
- uninstall Naxi at any time;
- remove Naxi's local application files, subject to normal Windows file permissions.

If a future version introduces telemetry, accounts, analytics, or another material form of personal-data processing, this Privacy Policy should be updated before or together with that change.

## 10. Changes to This Policy

We may update this Privacy Policy when the Application's functionality or data practices change.

The effective date at the top of this document indicates the latest version.

## 11. Contact

For privacy questions concerning Naxi Bootstrap, use the official project/community contact channel provided by the project owner.
